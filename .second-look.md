# Platform rules

Second Look reads this file from the main branch and applies it to every pull request.

## Tenancy

- Every query on a tenant-owned table (`WorkOrders`, `Customers`, `Wells`) must be limited to the current tenant. `PlatformDbContext` applies a global query filter for this.
- `IgnoreQueryFilters()` is not allowed outside `src/FieldOps.Api/Admin/`.
- Raw SQL (`FromSqlRaw`, `ExecuteSqlRaw`) skips the filter. It must include `TenantId` in its `WHERE` clause and must use parameters, never string concatenation.

## Access control

- Every controller action has an `[Authorize]` policy. Read actions use a `*.Read` policy and actions that change data use a `*.Write` policy.

## Migrations

- A migration must keep the data in existing rows. Use `RenameColumn` for renames.
- A new required column needs a backfill before the constraint is added.
- The pull request description must say what happens to existing rows.
- A migration comes with its designer file and the updated model snapshot.

## Auditing

- Any change to a work order or a customer writes an `AuditEntry` with the signed-in user and a UTC timestamp. The user comes from the session, never from the request body.

## General

- Times are stored in UTC (`DateTime.UtcNow`).
- No secrets, connection strings, or file paths in code.
